🌇 Vulkiris Shader Pack Guide (format v1.1)

A Vulkiris pack is a folder (or .zip) in the game's shaderpacks/ directory. Select it in game via O → Shader Packs…. Because packs are compiled by Minecraft's own shader compiler, one pack runs on both the OpenGL and Vulkan backends — write vanilla-dialect GLSL (#version 330, no layout(binding=…)).

Layout

shaderpacks/
└── my-pack/                (or my-pack.zip)
    ├── vulkiris.pack.json
    └── shaders/
        ├── first.fsh
        └── final.fsh

vulkiris.pack.json

{
  "name": "My Pack",
  "author": "you",
  "waterDepth": false,
  "passes": [
    { "fragment": "shaders/first.fsh", "scale": 0.5 },
    { "fragment": "shaders/final.fsh" }
  ]
}
FieldMeaning
passesUp to 8 fullscreen passes, run in order every frame after the world renders.
fragmentPack-relative path to the pass's fragment shader.
scaleOptional (default 1.0, range 0.1–1.0): output resolution relative to the screen — great for cheap blur chains. The last pass always draws full-resolution.
waterDepthOptional: when true, the depth buffer is snapshotted before water/translucent terrain draws and bound as WaterDepthSampler.

Writing a pass

Each pass is a fragment shader over a fullscreen triangle with in vec2 texCoord (0–1) and out vec4 fragColor. Declare only what you use from:

NameWhat it is
sampler2D SceneColorSamplerThe untouched scene, snapshotted before your passes ran
sampler2D SceneDepthSamplerThe live depth buffer (26.2 uses reversed depth: sky ≈ 0.0)
sampler2D PreviousSamplerOutput of the previous pass (first pass: the scene snapshot)
sampler2D WaterDepthSamplerPre-water depth snapshot (needs "waterDepth": true)
VulkirisParams blockTime, sun direction (view + world), camera position, matrices, fog color, and more

Pull in the shared uniform block (expanded by Vulkiris at load time), or your own pack files with quotes:

#moj_import <vulkiris:params.glsl>
#moj_import "lib/util.glsl"

Minimal example

#version 330

#moj_import <vulkiris:params.glsl>

uniform sampler2D PreviousSampler;

in vec2 texCoord;
out vec4 fragColor;

void main() {
    vec3 color = texture(PreviousSampler, texCoord).rgb;
    // Screen.z is world time in seconds:
    color *= 0.8 + 0.2 * sin(Screen.z * 3.0);
    fragColor = vec4(color, 1.0);
}
Iterate fast: edit your pack, then re-select it in the pack screen (or Refresh + click) — no game restart. Compile errors appear in the game log with the compiler's message; Vulkiris retries a few times, then falls back safely.

Tips

  • Depth → view-space position: unproject with InvProjection; see the built-in composite.fsh for the reversed-depth pattern.
  • The Vulkan backend validates more strictly than OpenGL — if a pack compiles on GL but not Vulkan, the logged ShaderCompileException says why.
  • Zip the pack folder to share it; zips load directly.

Iris parity status

Supported today: Iris-style composite/final post passes, per-pass scale, depth and water-depth inputs, shared uniforms, zip packs, live re-select.
Planned: multi-buffer targets, pack-defined settings surfaced in the Vulkiris UI, and translated terrain/entity programs — the vanilla Vulkan compiler is stricter than GL and the gbuffer model differs, so full Iris packs land incrementally.
